# IVCIS 高速入口智能视觉终端 - 项目宪章

## 1. 项目愿景

> **"让高速收费站入口无人化成为现实"**

本项目旨在开发一款基于 STM32H753ZI 的边缘智能视觉终端，用于高速公路收费站入口的车辆自动识别与违规拦截。通过端侧 AI 推理与云端协同，实现无人值守收费与智能预警。

## 2. 核心目标

| 目标 | 描述 | 优先级 |
|------|------|--------|
| **实时采集** | OV5640 摄像头连续采集车辆图像 | P0 |
| **端侧过滤** | TinyML 模型过滤无效背景，仅上报有效目标 | P0 |
| **高速上报** | 通过以太网将图像发送至云端进行车型/车牌识别 | P0 |
| **违规响应** | 检测到违规目标时触发声光报警 | P1 |
| **低置信预警** | 置信率过低时发出"车型不符"预警，转人工处理 | P1 |
| **自适应采集** | 根据光照条件智能调整摄像头参数 | P2 |
| **低功耗待机** | 无车时进入待机模式，有车来才唤醒拍摄 | P2 |

## 3. 硬件约束

| 资源 | 规格 | 备注 |
|------|------|------|
| **MCU** | STM32H753ZIT6 (Nucleo-144) | Cortex-M7 @ 480MHz |
| **SRAM** | D1: 512KB, D2: 288KB, D3: 64KB | ETH/DCMI 使用 D2 |
| **Flash** | 2MB | 含 AI 模型权重 |
| **摄像头** | OV5640 (DCMI 接口) | 最高 640x480@30fps |
| **网络** | LAN8742 PHY (RMII) | 100Mbps |
| **报警器** | GPIO 驱动蜂鸣器 + LED | 声光报警 |

## 4. 软件约束

| 约束 | 说明 |
|------|------|
| **RTOS** | FreeRTOS (CMSIS-RTOS v2) |
| **协议栈** | LwIP v2.1.2 |
| **AI 框架** | X-CUBE-AI (TFLite 部署) |
| **代码规范** | 单文件 ≤ 100 行，模块解耦 |
| **日志规范** | `[DEBUG|INFO|WARN|ERROR] [Module] Message` |

## 5. 不在范围 (Out of Scope)

- ❌ 云端服务器开发（仅提供 UDP 接口）
- ❌ 车牌识别算法（由云端完成）
- ❌ 收费结算逻辑
- ❌ 多路摄像头支持
