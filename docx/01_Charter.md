# IVCIS 工业智能相机 - 项目宪章

## 1. 项目愿景

> **"打造可靠、可扩展的工业智能相机边缘计算平台"**

本项目开发一款基于 STM32H753ZI 的工业智能相机，具备高清图像采集、多通道通信、云平台联动能力。适用于高速入口车型识别、产线视觉检测、远程监控等工业场景。

## 2. 核心目标

| 目标 | 描述 | 优先级 |
|------|------|--------|
| **实时采集** | OV5640 JPEG/灰度双模式连续采集 | P0 |
| **采集与传输并行** | 生产者-消费者模型，双缓冲流水线，采集不被网络阻塞 | P0 |
| **以太网图传** | UDP 零拷贝分片上传 JPEG 至云端/上位机 | P0 |
| **RS485 工业控制** | Modbus RTU 从站，PLC/HMI 读写参数、触发拍照 | P0 |
| **智能功耗管理** | 三级功耗状态机 (FULL/LIGHT/DETECT) | P1 |
| **云端协同** | 接收云端推理结果，执行报警/舵机动作 | P1 |
| **图像质量闭环** | 自适应曝光 + 模糊度评估 | P2 |
| **云平台接入** | MQTT 信令通道 (远期) | P2 |

## 3. 硬件约束

| 资源 | 规格 | 备注 |
|------|------|------|
| **MCU** | STM32H753ZIT6 (Nucleo-144) | Cortex-M7 @ 480MHz |
| **SRAM** | D1: 512KB, D2: 288KB, D3: 64KB | ETH/DCMI 使用 D2 |
| **Flash** | 2MB | 代码 + 只读数据 |
| **摄像头** | OV5640 (DCMI 接口) | JPEG 640x480 / Gray 160x120 |
| **以太网** | LAN8742 PHY (RMII) | 100Mbps |
| **RS485** | UART + MAX485 收发器 | 半双工, ≤115.2kbps |
| **报警器** | GPIO 驱动 LED (PB14) | 可扩展蜂鸣器 |
| **舵机** | TIM4_CH4 PWM (PD15) | 0°-180° |

## 4. 软件约束

| 约束 | 说明 |
|------|------|
| **RTOS** | FreeRTOS (CMSIS-RTOS v2) |
| **协议栈** | LwIP v2.1.2 (**Netconn API**, 线程安全) |
| **网络架构** | 双缓冲生产者-消费者, 帧队列解耦采集与传输 |
| **工业通信** | Modbus RTU 从站 (RS485) |
| **Transport 抽象** | 可插拔通信通道 (ETH / RS485) |
| **代码规范** | 单文件 ≤ 100 行, 模块解耦 |
| **日志规范** | `[DEBUG|INFO|WARN|ERROR] [Module] Message` |

## 5. 应用场景

| 场景 | 说明 | 所用功能 |
|------|------|----------|
| **高速入口车型识别与拦截** | 原始场景 — 连续抓拍车辆图像上传云端 AI 识别，违规时触发声光报警 + 舵机拦截 | 全部 |
| **产线视觉检测** | 工业产线上 PLC 通过 RS485 触发拍照，图像上传云端质检 | 采集 + RS485 + 图传 |
| **远程监控** | 无人值守场景，智能功耗管理 + 运动唤醒 + 自动上传 | 采集 + 功耗管理 + 图传 |

> 工业智能相机是通用平台，高速入口终端是其典型应用实例。所有原有功能 (IVCI/IVCR 协议、违规报警、舵机调角、三级功耗、帧差检测、自适应曝光) 完全保留并向后兼容。

## 6. 不在范围 (Out of Scope)

- 云端服务器 / AI 推理算法开发
- WiFi / BLE 无线通信 (工业环境可靠性不足)
- 多路摄像头支持
- 本地 AI 推理 (端侧 TinyML)
- 收费结算等业务逻辑
