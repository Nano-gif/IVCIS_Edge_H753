# 文档索引

本目录按“当前有效文档”和“历史/参考资料”分层维护。日常开发、面试讲解和代码实现优先阅读根目录下的有效文档；已被综合文档吸收的旧稿放入 `archive/`，避免多人协作时引用过期方案。

## 当前有效文档

| 文档 | 用途 |
|---|---|
| `01_Charter.md` | 项目边界、约束和协作规则 |
| `02_Requirements.md` | 当前功能需求和验收口径 |
| `03_Integrated_Project_Design.md` | 主设计文档: 背景、方案、软件、硬件、协议、场景、扩展 |
| `04_FileList.md` | 代码文件和模块职责索引 |
| `05_TaskBreakdown.md` | 后续代码实现任务和里程碑 |
| `06_Code Style.md` | 编码风格和命名约束 |
| `11_LCEDA_Schematic_Input_NUCLEO_Adapter.md` | NUCLEO-H753ZI 扩展 PCB 的立创 EDA 输入 |
| `12_Resume_Portfolio_Guide.md` | 简历项目经历和作品集话术 |
| `13_Portfolio_PPT_Script.md` | PPT 逐页正文和讲解结构 |

## 子目录

| 目录 | 内容 |
|---|---|
| `archive/` | 已被 `03_Integrated_Project_Design.md` 吸收的历史架构、协议、硬件和框图文档 |
| `reference/` | 数据手册、图片、格式模板等参考材料 |
| `work_notes/` | 上下文压缩、阶段进展、风险清单、云平台远期设想等过程记录 |

## 阅读顺序

1. 先读 `03_Integrated_Project_Design.md`，确认当前方案。
2. 需要写代码时读 `05_TaskBreakdown.md` 和 `04_FileList.md`。
3. 需要画硬件或 PCB 时读 `11_LCEDA_Schematic_Input_NUCLEO_Adapter.md`。
4. 需要求职展示时读 `12_Resume_Portfolio_Guide.md` 和 `13_Portfolio_PPT_Script.md`。

`archive/` 中的文档只作为历史细节参考，不作为当前实现依据。
