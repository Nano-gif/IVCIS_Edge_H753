## 3. 信号总线与接口一览

```
┌────────────────────────────────────────────────────────────────────────────┐
│                          STM32H753ZIT6                                     │
│                                                                            │
│  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐ │
│  │  RMII  │  │  DCMI  │  │ USART2 │  │ USART3 │  │  GPIO  │  │  SWD   │ │
│  │ 9 pins │  │ 13pins │  │ 3 pins │  │ 2 pins │  │ 6 pins │  │ 2 pins │ │
│  └───┬────┘  └───┬────┘  └───┬────┘  └───┬────┘  └───┬────┘  └───┬────┘ │
└──────┼───────────┼───────────┼───────────┼───────────┼───────────┼────────┘
       │           │           │           │           │           │
       ▼           ▼           ▼           ▼           ▼           ▼
  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌────────┐ ┌─────────┐ ┌────────┐
  │LAN8742A │ │ OV5640  │ │ MAX3485 │ │J5 UART │ │ OK1/Q1/ │ │J4 SWD  │
  │  PHY    │ │ Camera  │ │ RS485   │ │ Debug  │ │ LED×3   │ │Tag-Conn│
  └────┬────┘ └─────────┘ └────┬────┘ └────────┘ └─────────┘ └────────┘
       │                       │
       ▼                       ▼
  ┌─────────┐            ┌─────────┐    ┌────────┐    ┌────────┐
  │ J1 RJ45 │            │J3 RS485 │    │J7  DI  │    │J8  DO  │
  │ 100Mbps │            │ A/B/GND │    │光耦输入 │    │隔离输出│
  │ +ESD    │            │ +TVS    │    └────────┘    └────────┘
  └─────────┘            │ +120Ω   │
                         └─────────┘

  信号方向:
  ────────────────────────────────────────────────────────────
  RMII       : 双向 (MCU ↔ PHY)         100Mbps
  DCMI       : 单向 (Camera → MCU)      8-bit 并行 + 同步
  SCCB       : 双向 (MCU ↔ Camera)      GPIO 模拟 I2C, 100kHz
  USART2     : 半双工 (MCU ↔ RS485 总线) 9600~115200 bps
  USART3     : 双向 (MCU ↔ PC)          921600 bps (调试)
  DI (PC13)  : 输入 (外部 → MCU)        光耦隔离, 上拉
  DO (PD15)  : 输出 (MCU → 外部)        MOSFET 驱动, 隔离
  LED        : 输出 (MCU → LED)         PB0/PB7/PB14
  SWD        : 双向 (调试器 ↔ MCU)      PA13/PA14
```

## 4. 量产板连接器总表

| 位号 | 接口 | 物理形式 | 关键信号 | MCU 引脚组 |
|------|------|---------|---------|-----------|
| J1 | Ethernet | RJ45 + 磁性件 + ESD | RMII 9 线 | PA1/2/7, PB13, PC1/4/5, PG11/13 |
| J2 | DC IN | 2-3Pin 工业端子 | VIN+/VIN-/FG | 非 MCU |
| J3 | RS485 | 3Pin 端子 + TVS + 120R | A/B/GND | PD4/5/6 (经 MAX3485) |
| J4 | SWD | Tag-Connect / 2x5 1.27mm | SWDIO/SWCLK/NRST | PA13/PA14 |
| J5 | Debug UART | 4Pin JST | TX/RX/3V3/GND | PD8/PD9 |
| J6 | Camera | FPC/BTB 24P | D0-D7/HSYNC/VSYNC/PIXCLK/RST/PWDN/SCL/SDA | 15 pins |
| J7 | DI | 2Pin 端子 | DI+/DI- | PC13 (经光耦) |
| J8 | DO | 2-3Pin 端子 | DO+/DO- | PD15 (经 MOSFET) |
| J9 | RESET/BOOT | 按键/焊盘 | NRST/BOOT0 | NRST/BOOT0 |

## 5. 与参考设计的对比

| 参考图模块 | 本项目对应 | 差异说明 |
|-----------|-----------|---------|
| MIPI-CSI-2 Camera | DCMI 8-bit 并行 (OV5640) | 无 MIPI，使用传统并行接口 |
| Audio Codec + I2S | 无 | 工业相机不需要音频 |
| eMMC + MMC | 无 (可选 SD 扩展) | 基础版不含本地存储 |
| USB 2.0 | 无 (可选) | 基础版不含 USB |
| IR Illumination | 无 (可扩展) | 如需红外补光可外接 |
| PMIC (多路 Buck/LDO) | 分立 DCDC + LDO | 无需复杂 PMIC，三级降压即可 |
| PHY (Ethernet) | LAN8742A RMII | 相同，100Mbps |
| Load Switch | 无 | 无高边控制需求 |
| **新增: RS485** | MAX3485 + USART2 | 参考图无此模块，本项目工业必需 |
| **新增: DI/DO** | 光耦 + MOSFET | 参考图无此模块，工业联动必需 |
| **新增: 状态灯** | 3× LED (RUN/NET/ALM) | 工业产品必备 |
